# OpenAI 兼容模型接口

AI 研判统一使用 **Chat Completions** 协议，不需要安装本地模型服务。支持 DeepSeek 以及提供该协议的其他模型服务、中转站。

X 数据采集仍使用免费浏览器方案；模型调用费用、额度和网络要求由你填写的接口提供方决定。

## 页面配置

1. 打开工作台，点击顶部 **AI 接口**。
2. 填写 **Base URL**、**API Key**、**模型名称**。
3. 点击 **测试连接**。它会发送一条短请求（输出上限 32 token），显示成功或具体错误；不会保存配置。
4. 勾选 **开启 AI 双视角研判** 并点击 **保存接口**。
5. 点击 **立即扫描**。前 5 个话题由机会、质疑两个角色分别分析，其余话题仍用规则结果。

| 服务 | Base URL | 模型名称 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | 填写当前账号实际可用的模型 ID |
| 标准兼容中转站 | `https://你的服务商/v1` | 按服务商提供的 ID 填写 |
| 自定义前缀中转站 | `https://你的服务商/自定义前缀/v1` | 按服务商提供的 ID 填写 |
| 完整端点 | `https://你的服务商/v1/chat/completions` | 不会重复追加路径 |

DeepSeek 地址快捷按钮只填写地址，不指定模型或发送请求。[DeepSeek 兼容接口说明](https://api-docs.deepseek.com/)。其他提供方的具体兼容行为仍以其文档和测试结果为准。

## 配置保存与密钥

- 设置和密钥保存在本机 `data/intel.db`；页面和 API 只返回“密钥已保存 / 未保存”，不会返回原密钥。
- 保存时 API Key 留空，会保留同一接口已有的密钥；勾选“清除已保存密钥”可以删除。若同时填写新密钥，以新密钥为准。
- 更换接口地址时，必须重新填写密钥或明确清除旧密钥，防止把上一家服务的密钥带到新地址。
- 不把密钥写入运行事件、模型分析快照或导出简报，也不透传服务商原始错误响应。
- 运行中不能修改模型配置。每轮任务冻结开始时的模型配置，防止中途切换接口。
- 未配置或未启用 AI 时不发出模型请求。启用 AI 后，演示模式也需要点击扫描或明确开启自动扫描，不因首次打开页面自动调用模型。

## 高级参数

| 参数 | 默认 | 行为 |
| --- | --- | --- |
| 超时 | 60 秒 | 可设置 5–180 秒 |
| 输出 token 上限 | 800 | 每次请求，范围 100–4000 |
| JSON 模式 | 关闭 | 默认用提示词要求 JSON，兼容性更广 |

如启用 JSON 模式，会发送 `response_format: {type: "json_object"}`。若接口以 400/422 明确报告该参数不支持，同一请求最多去掉该参数重试一次；401、429、5xx 不自动重试。

正常每轮最多 10 次研判请求，最多 2 个话题同时分析。启用 JSON 模式且触发兼容回退时最多 20 次；测试连接单独计一次。输出上限不是总费用上限，输入原帖也可能参与计费。

JSON 可以带 Markdown 代码围栏，但必须是对象，包含 `text` 和非空 `evidence_ids`，引用必须来自该话题原帖证据。模型返回无效结构、错误引用、超时或接口错误时，页面显示原因并回退规则分析。合法引用不保证模型结论必然正确。

## 错误提示

- **401**：鉴权失败，检查 API Key。
- **403**：接口拒绝访问，检查模型权限。
- **404**：检查 Base URL、路径和模型 ID。
- **429**：限流或额度不足。
- **HTTP 5xx**：接口服务异常。
- **超时 / 连接错误**：检查网络、端口和证书。
- **返回格式不兼容**：接口需返回 `choices[0].message.content`；仅支持 Responses API 的地址不能直接使用。

远程地址使用 HTTPS；本机兼容端点可以使用 HTTP。请求不跟随重定向，避免 Authorization 被带到其他地址。

## 环境变量（可选）

没有通过页面保存过模型配置时，可从启动终端读取：

```text
OPENAI_BASE_URL=https://你的服务商/v1
OPENAI_API_KEY=你的密钥
OPENAI_MODEL=你的模型ID
```

界面保存后优先使用已保存配置。`.env.example` 是变量清单，不自动加载。旧版专用模型环境变量不再生效。
